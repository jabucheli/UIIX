# Instrucciones precisas para OpenCode  
## Mapa mental / diagrama de flujo — Recomendaciones de la tesis doctoral  
### Basado en `RECOMENDACIONES.docx` y en la lógica visual de `ejemplo.pptx`

---

# 1. Objetivo general

Desarrollar una **única diapositiva interactiva (16:9)**, con estética doctoral, limpia y esquemática, que sintetice las **recomendaciones** de la tesis mediante una estructura híbrida:

- **mapa mental**, porque las recomendaciones se agrupan por ámbitos;
- **diagrama de flujo**, porque la lectura debe ser secuencial y orientada a la aplicación.

La pieza debe comunicar, con **palabras clave**, que las recomendaciones se organizan en **tres ámbitos de aplicación**:

```text
Ámbito metodológico
→ Ámbito práctico
→ Ámbito académico
```

y que, dentro de cada uno, existen acciones concretas de fortalecimiento, aplicación y proyección futura. Esta organización por ámbitos está expresamente establecida en el documento de recomendaciones. fileciteturn26file0L2-L7

---

# 2. Fuente obligatoria

Usar como base exclusiva:

```text
RECOMENDACIONES.docx
```

No añadir recomendaciones no sustentadas.  
No alterar los ámbitos.  
No cambiar el sentido técnico del documento.

---

# 3. Idea central que debe comunicar la diapositiva

La diapositiva debe permitir explicar oralmente lo siguiente:

```text
Las recomendaciones del estudio se organizan en tres ámbitos:
metodológico, práctico y académico.
```

Además, debe dejar ver que:

```text
la estrategia puede ampliarse,
aplicarse operativamente en obra,
actualizarse de forma permanente
y servir de base para investigaciones futuras.
```

# 4. Formato general

## 4.1. Tamaño del lienzo

Usar formato:

```text
16:9
```

Resolución sugerida:

```text
1600 × 900 px
```

o

```text
1920 × 1080 px
```

si se desea mayor nitidez.

---

## 4.2. Estilo visual

Debe mantener el estilo del archivo `ejemplo.pptx`:

- fondo blanco;
- uso dominante de **verde** y **rojo**;
- títulos sólidos;
- tarjetas redondeadas;
- estructura esquemática;
- palabras clave;
- jerarquía visual muy clara;
- apariencia académica, no comercial.

Evitar:
- párrafos largos;
- exceso de texto corrido;
- tablas visibles de manera permanente;
- bloques sobrecargados;
- ornamentos innecesarios.

# 12. Lógica de flujo inferior

Añadir una banda inferior o una secuencia horizontal muy breve con la siguiente lógica:

```text
Ampliar → Aplicar → Actualizar → Investigar
```

### Significado

- **Ampliar** = instrumentos y enfoques;
- **Aplicar** = ART, SST y alineación normativa;
- **Actualizar** = instrumentos dinámicos;
- **Investigar** = continuidad académica.

# 14. Interactividad obligatoria

El usuario pidió que, **de ser el caso**, al hacer click sobre cada bloque se amplíe la información.  
Por lo tanto, la implementación debe incluir expansión interactiva.

## 14.1. Bloques clicables

Todos los siguientes deben ser clicables:

- Ámbito metodológico
- Subbloque 1
- Subbloque 2
- Ámbito práctico
- Subbloque 3
- Subbloque 4
- Subbloque 5
- Ámbito académico
- Subbloque 6

## 14.2. Comportamiento al hacer click

Al hacer click, debe abrirse:

- un **modal central**, o
- un **drawer lateral**, o
- una **tarjeta expandible superpuesta**.

## 14.3. Contenido del panel expandido

Cada expansión debe incluir:

1. título del bloque;
2. 2–5 ideas detalladas;
3. frase interpretativa;
4. botón cerrar.
